title: Manual

The manual is split into four main parts:

1. [User manual](user_manual/index.html): this covers documentation and information useful for
   people who want to run GS2
2. [Developer manual](developer_manual/index.html): this covers documentation and
   important information for people interested in modifying and developing GS2
3. [Namelists](namelists/index.html): this is an autogenerated list of tables of the various
   namelists used in GS2
4. [Admin manual](admin_manual/index.html): this documents administrative tasks, like making releases

If you're new to GS2, [start here](user_manual/index.html)!
