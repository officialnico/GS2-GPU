title: Manual

The manual is split into three main parts:

1. [Developer manual](developer_manual/): this covers documentation and
   important information for people interested in modifying and developing GS2
2. [Namelists](namelists/): this is an autogenerated list of tables of the various
   namelists used in GS2
3. [User manual](user_manual/): this covers documentation and information useful for
   people who want to run GS2

If you're new to GS2, [start here](user_manual/index.html)!
